# devops-playground

This repository currently holds the architecture and system design for **Career OS** (working title): a single-user, agentic web application that tracks the roadmap from Software Engineering Lead to Software Architect while linking it to measurable results in the current role.

Nothing has been built yet. The `docs/` folder is the input for a Spec Driven Development workflow with GitHub Spec Kit, which is initialised here (version 1.1.1.dev0, Claude Code integration: skills under `.claude/skills/speckit-*/`, scaffold under `.specify/`). Start at [`docs/README.md`](docs/README.md); the Spec Kit runbook is [`docs/05-spec-kit-handoff/01-handoff-guide.md`](docs/05-spec-kit-handoff/01-handoff-guide.md).
